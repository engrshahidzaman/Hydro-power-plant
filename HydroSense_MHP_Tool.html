📐Euler's Turbomachinery Equations
Euler Head: H_e = (U₁·Cᵤ₁ − U₂·Cᵤ₂) / g
Hydraulic Eff: η_h = H_e / H_net × incidence_factor
Jet velocity: C₁ = √(2·g·H) ← Torricelli's theorem
Runner speed: U₁ = π·D·N / 60
Whirl inlet: Cᵤ₁ = C₁·cos(α₁)
Whirl exit: Cᵤ₂ = U₂ − Wr₂/tan(β₂) ← zero if β₂=90°
Incidence: Δβ = |β₁_design − β₁_actual| → loss ∝ Δβ²
Specific Speed: Nₛ = N·√Q / H^0.75
Speed Ratio: φ = U₁/C₁ ← optimal: 0.46 (Pelton), 0.35 (Crossflow)

📐Loss Formula Reference
1. Pipe (Darcy-Weisbach): h_f = f·(L/D)·V²/(2g) | f = Swamee-Jain approximation
2. Hydraulic (Blade): h_h = k·(incidence angle Δβ)²/(2g) + shock at entry
3. Volumetric (Leakage): Q_leak ≈ 0.5–2% Q → η_v = Q_useful / Q_total
4. Mechanical (Bearing): P_mech = P_in × (ξ_bearing + ξ_seal) / 100
5. Disk Friction: P_df = k_df · ρ · ω³ · R⁵ ← increases as N³
6. Copper Loss: P_cu = I²·Ra (Ra = armature winding resistance)
7. Iron Loss: P_fe = k_h·f·B²_max + k_e·f²·B²_max (hysteresis + eddy)
8. Exit Kinetic Energy: h_exit = C₂²/(2g) ← recovered by draft tube
